# Expense Tracker + Spending Analytics

A CLI-based fintech project built using Python and SQLite.

## Features

- Add income and expense transactions
- View all transactions
- Update transactions
- Delete transactions
- Search transactions by category
- Financial reports
- Spending analytics
- Budget alerts
- Financial health score

## Tech Stack

- Python
- SQLite
- SQL (CRUD operations)

## Project Structure

```text
expense_tracker/
│
├── main.py
├── database.py
├── analytics.py
├── README.md
```

## How to Run

1. Clone the repository

```bash
git clone https://github.com/atul220805-dev/expense-tracker-python.git
```

2. Open project folder

3. Run:

```bash
python main.py
```
